# 바운스 브레이커 — 코드 구조 계약서 (리드 관리)

모든 모듈은 이 문서의 이름·형태를 그대로 쓴다. 바꿔야 하면 임의로 고치지 말고 리드에게 보고한다.
순수 ES 모듈(`<script type="module" src="js/main.js">`), 외부 라이브러리·이미지 파일 없음.

## 1. 파일 소유
| 파일 | 소유 | 내용 |
|---|---|---|
| `js/events.js` | 리드 | `bus`(on/off/emit), `store`(get/set, try/catch) — 이미 있음 |
| `docs/구조.md`, `CLAUDE.md` | 리드 | 이 문서 |
| `docs/기획서.md`, `js/data.js` | 기획자 | 모든 숫자·콘텐츠 (단 `WORLDS`의 `line`/`bg` 색은 디자이너) |
| `js/board.js`, `js/physics.js`, `js/main.js` | 개발자 | 판 생성·물리·게임 상태/루프/입력/데미지/적 능력/`__bb` |
| `docs/디자인.md`, `index.html`, `css/style.css`, `js/render.js`, `js/ui.js` | 디자이너 | 화면·그림·HUD·카드 UI |
| `docs/테스트보고서.md` | 테스터 | 검증 결과 (코드는 수정 안 함) |

## 2. 좌표계·공통 판 틀
- 논리 판 크기 **375 × 667**. main.js가 `#stage` 요소 크기에 맞춰 확대/레터박스(view 계산).
- 적 전용 맵 오브젝트 영역: **x 30~345, y 60~450**. 그 아래는 모든 적 공통 틀.
- 공 반지름 9 (거대화 시 13.5). 물체끼리 최소 30px 간격.
- 공통 틀(board.js가 생성, 대략 위치 — 개발자가 최종 결정 후 `docs/구조.md` 부록에 실측값 기록 요청 가능):
  - 바깥 벽: 좌 x=12, 우 x=345(필드쪽), 위 y=20 부근, 위쪽 모서리는 둥근 곡선(여러 캡슐).
  - 발사 레인: 오른쪽 x 348~372, 아래 y≈640 에서 위로 → 상단 곡선을 타고 필드로 진입.
  - 슬링샷: 좌/우 y 500~560 삼각형 빗변(튕김 강함).
  - 인레인/아웃레인 가이드 벽: 슬링샷 바깥.
  - 플리퍼: 좌 피벗 (112, 600), 우 피벗 (263, 600), 길이 ≈62, 쉬는 각 아래로 30°, 올림 각 위로 25°.
  - 배수구(드레인): 플리퍼 사이 아래, y > 667 로 나가면 공 소실.

```js
export const CONST = { W:375, H:667, BALL_R:9, GIANT_MUL:1.5, BALLS_PER_RUN:3, STAGES:25,
                       GRAVITY, MAX_SPEED, LAUNCH_MIN, LAUNCH_MAX, SUBSTEP:1/600, ... };
export const DAMAGE = { bumper, lane, target, body, weakMul, resistMul, critChance, critMul, ... };
export const STATUS = { burn:{...}, poison:{...}, freeze:{...}, shield:{...}, ... };  // 수치

export const UPGRADES  = { id:{ id, name, desc, rarity, max, ... } };

                           abil:[{ t:'shield', every:6, ... }], map:{ b, l, t, w, e }, boss? } ];
export const WORLDS    = [ /* 5개, 5스테이지씩 */ { id, name, line:'#..', bg:['#..','#..'] } ];

export function makeEnemy(stage) {}       // → 적 인스턴스 (아래 G.enemy 형태, hp 공식 포함)

```
맵 형식 (적 전용, 영역 x 30~345 / y 60~450):
- `b`: 범퍼 `[[x, y, r], ...]` (r 14~24)
- `l`: 레인(통과형, 충돌 없음) `[[x, y, w, h], ...]`
- `t`: 드롭 타깃(캡슐) `[[x, y, len, angleDeg], ...]`
- `w`: 추가 벽(캡슐, 데미지 없음) `[[x1, y1, x2, y2], ...]`
- `e`: 적 몸체 `[x, y, r]` (생략 시 `[187, 140, 26]`, 보스는 r 더 크게)

## 5. 게임 상태 `G` (main.js 소유, render/ui는 읽기만)
```js
G = {
  phase: 'title'|'launch'|'play'|'cards'|'paused'|'gameover'|'victory',
  stage: 1, world: 0, score: 0, best: 0, time: 0,
  ballsLeft: 3,                         // 남은 공(목숨). 지금 판 위 공 포함 X
  material: 'normal',                   // 재질 id (1개)
  traits: [],                           // 특성 id (최대 4)
  upgrades: {},                         // { id: 횟수 }
  enemy: { name, shape, color, weak, resist, boss, hp, maxHp, x, y, r, vx, vy,
           status: { shield:0, freeze:0, burn:0, poison:0, ... },   // 남은 시간/스택/수치
           abil: [{ t, every, timer, ... }], guards: [{ x, y, r, vx, vy }] },
  balls: [{ x, y, vx, vy, r, alive, inLane }],   // 판 위 공(멀티볼 가능)
  plunger: { charge: 0, holding: false },        // 0~1
  flippers: { L: { angle, up }, R: { angle, up } },
  cards: [],                            // phase==='cards' 일 때 고를 카드
  stats: {},                            // 특성·강화 반영된 최종 수치 (dmgMul, critChance 등)
}
```
`board` (board.js `buildBoard(enemy)` 반환, render가 그림):
```js
board = { walls:[{x1,y1,x2,y2,r}], bumpers:[{x,y,r,flash}], lanes:[{x,y,w,h,lit}],
          targets:[{x1,y1,x2,y2,r,down,timer}], slings:[{x1,y1,x2,y2,r,side,flash}],
          flippers:{ L:{px,py,len,r,rest,up}, R:{...} }, lane:{x1,x2,y1,y2}, drainY }
```
`flash`/`lit`은 0~1 값으로 main이 맞으면 1로 세팅하고 감쇠 → render가 빛나는 연출에 사용.

## 6. 모듈 함수
- **render.js** (디자이너): `initRender(canvas)`, `resizeRender(view)` (view = `{cssW, cssH, dpr, scale, offX, offY}`), `drawFrame(G, board, dt)`. 이펙트는 bus 구독. 재질 외형은 `LOOK[materialId]`.
- **ui.js** (디자이너): `initUI(api)` — api = `{ start(), pause(), resume(), chooseCard(i), restart(), toTitle() }`; `updateUI(G)` 매 프레임 (DOM은 값이 바뀔 때만). 카드 화면은 `cards` 이벤트로 열고, 고르면 `api.chooseCard(i)`.
- **main.js** (개발자): 부트스트랩, `#stage` 크기에 맞춘 view 계산 & 캔버스 크기 설정, rAF 루프(물리 1/600초 서브스텝), 입력, `hit()`, `moveEnemy()`, `triggerAbility()`, `__bb`.
- **index.html**에는 `#stage` 안에 `<canvas id="board">` 가 있어야 한다. 나머지 DOM은 디자이너 자유.

## 7. 입력 (main.js)
- Pointer Events, 멀티터치. `#stage` 위:
  - phase `launch`: 누르고 있으면 plunger.charge 증가(1초에 0→1), 떼면 발사.
  - phase `play`: 화면 왼쪽 절반 누름 = 왼쪽 플리퍼, 오른쪽 절반 = 오른쪽 플리퍼 (손가락별 추적).
- 키보드: ←/Z 왼쪽, →/M 오른쪽, Space 발사(누르고 떼기), P/Esc 일시정지.
- UI 버튼(DOM)은 이벤트 전파를 막아 플리퍼와 겹치지 않게 (디자이너).
- 탭 숨김(`visibilitychange`) 시 자동 일시정지.

## 8-1. 기획 반영 추가 사항 (확정)
- data.js 추가 export: `CARD_RULES`, `enemyHp`, `rarityTable`, `calcStats(G)` — main.js는 카드 선택 후 `G.stats = calcStats(G)`.
- 추가 필드: ENEMIES `tip`, MATERIALS `look`, 카드 `tag:'weak'|'resist'`, G.enemy `x0,y0,t,tpIdx,stage,tip,map`, guards `ang,hp`.
- ENEMIES는 `/*ENEMIES_JSON_BEGIN*/ … /*ENEMIES_JSON_END*/` 사이 JSON (tools/check_maps.py가 파싱).
- 레인 `[x,y,w,h]`의 x,y = 왼쪽 위. 타깃 x,y = 중심.
- 실제 맵 사용 범위 x 42~315, y 60~450. 발사 레인 진입 구역(x>270, y<95)은 비워 둠.
- 데미지 순서·능력·재질·특성 동작은 **docs/기획서.md 8장**이 기준.

## 8-2. 변경 (판 5종·재질 다중 보유)
- 판 5종 (`board.js FRAMES`) — 구조 자체가 다르다:
  - 거울 요새: 발사 레인이 **왼쪽**, 오른쪽 벽 중간에 세 번째 플리퍼.
  - 모래시계: 가운데 허리로 나뉜 두 방, 허리에 작은 플리퍼 2개 (플리퍼 4개).
  - 킥아웃 계곡: 왼쪽 벽 **킥아웃 구멍**(공을 0.7초 잡았다가 적을 향해 1250 속도로 쏨, 피해 `pocket` 10) + 왼쪽 바깥 통로 **킥백**(9초마다 한 번 빠지는 공을 쳐 올림).
  - 두 갈래 섬: 가운데 섬(양옆이 슬링)이 배수구를 둘로 나누고, 플리퍼는 양쪽 벽에 붙음.
  - 쌍둥이 포켓: 발사 레인 왼쪽, 양쪽 벽에 킥아웃 구멍, 넓은 플리퍼.
- `board.lane.side` ('L'/'R'), `inLaneBand(board, x)`, `board.flipperList` (같은 쪽 플리퍼는 `G.flippers[side]` 각도를 같이 씀), `board.pockets`, `board.kickbacks`, `board.spawn` (쌍둥이 공 추가 위치). 수치는 `DEVICES`.
- 레인이 왼쪽인 판은 `fit.mirror` 로 적 맵을 좌우로 뒤집어 입구 자리를 비운다. 디버그 `__bb.boardFor(stage, frame)` 로 판·맵 간격 검사 가능 (최소 21.7px).
- **판은 스테이지마다 바뀐다**: `frameIndexOf(stage) = ((stage-1) % 5 + world) % 5` → `G.frame`. 이어지는 두 스테이지는 항상 다른 판.
- 적 맵은 `fitEnemy(enemy, G.frame)`가 판의 `fit {s, cx, cy}`로 축척·이동 (맵·적 위치·이동 폭·호위병 궤도·순간이동 지점 포함). `buildBoard(enemy, G.frame)`.
- **판마다 장애물이 다름** (`GIMMICKS`, 범퍼 자리에 놓임, `board.gimmick`): 팔각 요새=숨쉬는 범퍼(pulse), 둥근 돔=떠도는 범퍼(orbit), 좁은 탑=회전 막대(spin), 지그재그 협곡=부서지는 바위(crumble, 3타 후 부서지며 bank 피해·5초 뒤 재생, `crumble` 이벤트), 쌍둥이 깔때기=소용돌이(whirl, 공을 끌어당김). 움직임은 `main.js updateGimmicks`, 충돌은 `collideBall`.
- 범퍼 필드 추가: `kind, x0, y0, r0, vx, vy, i, ph, ang, av, hp, broken`.
- **적 처치 연출**: `defeat()` → phase `dying` (`G.dieT`, `G.dieDur` = `DIE_TIME` 1.7초 / 보스 `DIE_TIME_BOSS` 3초) → `afterDefeat()` 에서 `cards` 또는 `victory`. 연출은 render.js `drawDying` (떨림·깜빡임·부풀기 → 펑, 번쩍임·화면 흔들림·파편, 보스는 작은 폭발 여러 번). `enemyDefeated` 이벤트에 `bonus, x, y, balls` 추가.
- 그림은 픽셀 테마(`render.js`): 판을 1/2 해상도로 그린 뒤 Bayer 디더링 → 정수 배율 확대. 월드마다 장애물 겉모습(`SKIN`: 버섯·바위·수정·톱니·코일)이 다름. 글자는 Galmuri11(fonts/, OFL).
- `G.materials`: 고른 재질 전부. 새 공(`toLaunch`)마다 그중 하나를 무작위로 `G.material`에 넣고 `calcStats` 재계산. 재질 카드는 이미 가진 재질 제외.
- 적 HP 증가율 `HP_GROWTH` 1.12 → 1.17.
