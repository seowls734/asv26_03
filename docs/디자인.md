# 바운스 브레이커 — 디자인 규칙 (디자이너)

방향: **가볍고 단순하게.** 캔버스 도형·단색·약한 그라데이션만. 이미지 파일·파티클·shadowBlur 없음. 정보 전달(재질·적 상태·데미지 의미)은 확실하게.

## 1. 파일
| 파일 | 내용 |
|---|---|
| `index.html` | `#app` 안에 `#hud`, `#stage > canvas#board`, 오버레이 `#scrTitle` `#scrCards` `#scrPause` `#scrEnd` |
| `css/style.css` | 레이아웃·HUD·카드·버튼, 재질 견본 `.swatch.<id>` |
| `js/render.js` | `initRender` / `resizeRender` / `drawFrame`, `LOOK`, 데미지 숫자·능력 이름 |
| `js/ui.js` | `initUI(api)` / `updateUI(G)` |

## 2. 레이아웃
- 세로(375×812): HUD 3줄 얇은 바(판 위) → `#stage`가 나머지 전부. 가로(높이 ≤600): HUD가 왼쪽 210px 세로 바.
- `#stage`·`#board`: `touch-action:none`. `#app`은 `env(safe-area-inset-*)` 패딩.
- 버튼 높이 ≥44px(일시정지 버튼은 투명 확장 영역), 글자 ≥12px, 중요 숫자 14px.
- 모든 버튼·오버레이·HUD는 `pointerdown` 전파를 막는다 → 플리퍼 입력과 안 겹침.
- 캔버스 글자는 판 배율이 작을 때(가로) 최대 1.8배 키운다.

## 4. 적
- 모양: blob(출렁이는 원) · box(둥근 사각) · spike(가시 10개, 천천히 회전) · ghost(돔+물결 아래) · eye(큰 흰자+홍채, 공을 바라봄). 나머지는 두 눈이 공을 바라봄. 색 = `ENEMIES.color`. 보스는 노란 왕관 + HP 바 금테.
- HP 바: 몸 위. 초록 >50% · 노랑 >20% · 빨강. 위에 남은 HP 숫자. 보호막 중엔 바 위 파란 줄.
- 상태: 보호막 = 파란 고리 · 빙결 = 하늘색 덮개+흰 테 · 화상 = 주황 테 · 독 = 녹색 점선 · 적응 = 내 재질 색 점선 큰 고리 · 격노 = 빨간 테. 몸 아래 글자 배지(보호N/빙결/화상N/독N/적응/격노).
- 능력 예고(`abil[].warn`) = 몸 옆 노란 "!" 깜빡임. 기울임 = 판 위 노란 화살표 3개(`tiltDir`, 예고 중엔 흐리게). 마비 = 해당 플리퍼 어둡게 + "마비".
- 호위병: 회색 원 + 흰 테, 안에 남은 hp 점.

## 5. 이펙트 (bus 구독)
| 이벤트 | 표시 |
|---|---|
| `hit` | 숫자 위로 떠오르며 0.85초 사라짐. weak=노랑 24px "N!" · crit=빨강 21px "치명 N" · resist=회색 13px · normal=흰 15px · shield=파랑 "막음" · dot=주황(독은 녹색) 12px |
| `ability` | 적 위 주황 18px 능력 이름 1.3초 |
| `enemyDefeated` | 가운데 "격파!"/"보스 격파!" |
| `ballLost` | 아래쪽 "공 소실" |
- 범퍼 `flash`>0 → 흰색으로 + 살짝 커짐. 슬링 `flash` → 흰색. 레인 `lit` → 채움 진하게 + 흰 화살표. 타깃 `down` → 얇은 흐린 선(서 있으면 노란 캡슐).
- 발사 레인: 플런저가 `plunger.charge`만큼 내려가고, 레인 왼쪽에 충전 게이지(초록→노랑→빨강).

## 6. 월드 색 (`WORLDS.line` / `bg`)
이끼숲 #7be08a · 모래협곡 #ffb35c · 얼음굴 #8fe3ff · 대장간 #ff6a4d · 첨탑 #ffe45c. bg는 위→아래 세로 그라데이션 2색. 벽·범퍼·레인은 line 색.

## 7. 카드
- 종류 태그 색: 재질 주황 · 특성 초록 · 강화 파랑. 등급 테두리: 일반 회색 · 희귀 파랑 · 영웅 보라.
- `tag:'weak'` → 노란 "다음 적 약점", `'resist'` → 회색 "다음 적 저항". 강화는 "Lv 다음/최대".
- 위쪽에 다음 적(ENEMIES[G.stage]) 이름·약점·저항·능력 설명. 숫자키 1~4로도 선택.

## 8. render·ui 가 읽는 필드 (개발자 확정값 반영)
- 플리퍼: `G.flippers.L/R.angle` 화면 좌표 라디안, 끝 = 피벗 + len·(cos,sin). 없으면 `board.flippers.*.rest`.
- 벽 `gate:true` = 점선 얇게(일방 문), `map:true` = line 색 75%. `board.plunger{x,y}` 아래에 플런저, `targets[].flash` = 흰색.
- `G.saveFlash>0` → 판 가운데 초록 "SAVE" 깜빡임. `ballLost` 의 `saved`/`left<0` 는 "공 소실" 생략.
- `abil[].warn` → 노란 "!" 깜빡임. 오버레이·HUD 에는 `data-ui`(+`.ui-block`) → main 의 플리퍼 입력이 무시.
- 카드 화면은 `api.getG()` 로 최신 G 를 읽고, 다음 적 = `ENEMIES[G.stage]`. 일시정지 화면에 소리 켜기/끄기(`api.setMuted`).
