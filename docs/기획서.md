# 바운스 브레이커 — 기획서 v1 (25스테이지판)

> 숫자는 모두 `js/data.js` 에 있다. 이 문서와 data.js가 다르면 **data.js가 기준**이다.
> 범위: 월드 5개 × 5스테이지 = **25스테이지**, 적 25종(5번째마다 보스), 재질 8 · 특성 16 · 강화 10 · 적 능력 11종.

## 1. 게임 개요 · 한 판 흐름

핀볼 판에서 공을 튕겨 **데미지 구간**(범퍼·레인·타깃·적 몸체)을 지나가게 해서 판 위쪽의 적을 쓰러뜨린다. 적을 쓰러뜨릴 때마다 카드 1장을 골라 공을 키운다.

| 단계 | phase | 내용 |
|---|---|---|
| 시작 | `title`→`launch` | 1스테이지, 재질 `normal`, 특성·강화 없음, `ballsLeft = BALLS_PER_RUN(3)` = **예비 공** (발사대 공은 따로) |
| 발사 | `launch` | 누르고 있으면 충전(1초에 0→1), 떼면 `LAUNCH_MIN + (MAX-MIN)·charge` 속도로 발사 |
| 플레이 | `play` | 좌/우 반쪽 터치 = 좌/우 플리퍼. 데미지 구간을 지날 때마다 `hit()` |
| 데미지 | — | 범퍼 4 · 레인 3 · 타깃 8 · 몸체 12 (+배수, 8장 A) · 타깃 전부 쓰러뜨림 = 보너스 25 |
| 격파 | → `cards` | 점수 +100×stage (보스 +500), 보스면 공 +1 (최대 5). 판 위 공은 모두 회수 |
| 카드 | `cards` | 3장(행운 4장) 중 1장 고름 → `G.stats = calcStats(G)` |
| 다음 스테이지 | `launch` | stage+1, 새 적·새 맵, 공은 발사대에서 시작 (목숨 소모 없음) |
| 공 소실 | — | 판 위 마지막 공이 배수구로 → `ballsLeft−1` 후 `launch`. 이미 0이었으면 `gameover` |
| 승리 | `victory` | 25스테이지 보스 격파 |

- 스테이지 사이 HP·상태는 넘어가지 않는다 (적은 매번 새로, 내 카드는 유지).
- **카드 화면에 다음 적의 이름·약점·저항·능력을 보여 준다** (머리 쓰는 핵심 정보, ui.js).

## 5. 카드 등급 · 확률 · 뽑기 규칙 (`rollCards`, `CARD_RULES`)

| 항목 | 값 |
|---|---|
| 장수 | 3장, `lucky` 보유 시 4장 |
| 등급 확률 (일반/희귀/전설) | 평소 62/30/8 %, **보스 격파 직후 30/48/22 %** |
| 스테이지 보정 | 스테이지당 일반→희귀 0.5%p 이동 (최대 12%p) |
| 행운 보정 | 일반에서 5%p 빼서 희귀·전설에 반씩 |
| 종류 가중치 | 재질 25 · 특성 30 · 강화 45 |
| 약점 힌트 | 40% 확률로 **다음 적의 약점 재질** 카드 1장을 먼저 넣고 `tag:'weak'` (다음 적 저항 재질이 나오면 `tag:'resist'`) |

뽑기 순서: ① 약점 힌트 판정 → ② 남은 칸마다 종류(가중치, 후보 남은 종류만) → 등급 → 그 종류·등급 후보 중 무작위, 해당 등급이 없으면 그 종류 아무 등급.
제외 규칙: 지금 재질·`normal` 재질 / 보유 특성 / **특성 4개면 특성 카드 전부** / 최대 레벨 강화 / 공 5개면 `extraBall`. 한 번에 같은 카드 중복 없음. 카드 형태 `{ kind, id, rarity, tag? }`.

## 8. 개발자에게 넘길 새 로직 (data.js 숫자만으로 안 되는 것)

모든 수치는 `G.stats = calcStats(G)` (카드 고를 때마다 다시 계산) 와 `STATUS`, `DAMAGE` 에서 읽는다.

### A. `hit(src, obj)` 데미지 계산 (src: bumper/lane/target/body/bank/chain/burn/poison)
1. 같은 물체 `HIT_CD`(레인 `LANE_CD`) 안 재타격 무시. 호위병 충돌은 데미지 대신 `guard.hp −= stats.guardHits`, 0이면 제거.
2. **재질 타격 효과 먼저 처리** (보호막에 막혀도 적용): 8장 C.
3. 보호막: `status.shield>0` 이고 src가 직접 타격(bumper/lane/target/body/bank/chain) 또는 burn → `shield −= stats.shieldHits` (최소 0), 0피해, kind `'shield'`, 끝. **poison은 통과**.
4. `base = DAMAGE[src]` (chain = `DAMAGE.bumper × stats.chainMul`, burn/poison = 틱 피해 8장 C)
5. 출처 배수: bumper→`bumperMul`, lane→`laneMul`, target·bank→`targetMul`, body→`bodyMul`, burn·poison→`dotMul`, chain→1
6. `× stats.dmgMul` (burn/poison 은 dmgMul 미적용)
7. 원소: (직접 타격 & 적응 중) → `stats.resistMul` / 아니면 material===weak → `weakMul`, ===resist → `resistMul`, normal → 1. 지속 피해(burn/poison)도 약점·저항은 적용, **적응은 미적용**
8. 치명(직접 타격만): `rng < critChance` → `× critMul`, kind 'crit'
9. 빙결 중 `× STATUS.freeze.takenMul`, 마무리 보유 & hp ≤ 20% → `× 1.5`
10. 갑옷(직접 타격만, poison 무시): `a = max(0, flat − armorCut) × armorMul × (화상 중 0.5)`; `dmg = max(DAMAGE.min, round(raw − a))`
11. hp 감소, 점수 += dmg, `hit` emit (kind 우선순위 crit > weak > resist > normal, 틱은 'dot'). hp ≤ 0 → 격파.
- 연쇄 방지: chain 번개는 4번째 타격 카운트에 포함하지 않는다.
- bank: 맵의 타깃이 모두 down 되면 src 'bank' 1회 후 전부 즉시 재설치. 개별 타깃은 `stats.targetReset` 초 뒤 재설치.
- 첫 타격·연타 같은 시간 의존 보너스는 이번 판에 없음.

### B. 적 능력 (`G.enemy.abil[]`, 타이머는 `play` 중에만, **빙결 중 정지**)
- 주기형 공통: `timer −= dt`; `timer ≤ ABIL_WARN` 이면 `warn=1` (render 예고). `timer ≤ 0` → 발동 + `ability {t,label,x,y}` emit, `timer = every × stats.cdMul × (격노 ? cdMul : 1)`.

| t | 동작 |
|---|---|
| move | 적 시간 `et`(빙결 중 정지, 격노 시 ×spdMul 속도로 증가): `x = x0 + ax·sin(spd·et)`, `y = y0 + ay·sin(2·spd·et)`. vx,vy는 미분값, `ENTITY_MAX_V` 로 제한해 hitCapsule 에 전달 |
| shield | `status.shield = max(status.shield, hits)`. 깨질 때까지 유지 |
| heal | `hp += maxHp·pct·(1−stats.healCut)·(독 스택>0 ? 1−STATUS.poison.healCut : 1)`, maxHp 상한 |
| armor | 지속. A-10 에서 사용 |
| guard | 시작 시 n기(`makeEnemy` 가 만듦). 각도 `ang += spd·dt`(빙결 중 정지), 위치 = 적 중심 + orbit·(cos,sin). `every` 초마다 n기 미만이면 1기 보충(hp GUARD_HITS). 공과 충돌하는 원(r GUARD_R) |
| tp | `tpIdx=(tpIdx+1)%pts.length`, `x0,y0 = pts[tpIdx]`. 도착 지점 (r+30) 안에 공이 있으면 0.1초씩 미룸. 호위병은 같이 이동 |
| push | 적 중심에서 `radius` 안의 공: `v += 방향 × power × (1−d/radius) × stats.forceMul` |
| tilt | `status.tilt = dur`, `tiltDir = ±1` (예고 시작 때 정해서 render 가 화살표 표시). 그 동안 공에 `ax × tiltDir × stats.forceMul` 가로 가속 |
| jam | 예고 시작 때 `jamSide = 'L'|'R'` 무작위. 발동 시 `status.jam = dur`, 그 동안 그 플리퍼 입력 무시(내려감). `stats.jamImmune` 이면 발동만 표시하고 효과 없음 |
| adapt | `status.adapt = dur`. 그 동안 직접 타격은 A-7 에서 지금 재질(normal 포함)에 저항 |
| rage | 주기형 아님. hp ≤ at·maxHp 처음 될 때 `raged=true`, `ability` emit. 이후 모든 주기형 간격 ×cdMul, move 속도 ×spdMul |

## 9. 밸런스 점검 — 너무 센 조합

- **약점/저항 격차**: 약점 ×1.8 / 저항 ×0.5 → 같은 공으로 3.6배 차이. 월드 4는 화염 저항·서리 약점, 월드 5는 번개 저항·고무 약점이라 재질 교체 판단이 매 월드 필요하다. 약점 힌트 카드(40%)로 운이 나빠도 기회가 온다.
- **화염 몰빵**(화염+원소 증폭+재질 숙련5+지속 피해5+저주): 화상 8스택 dps = 8×1.2×2.25×2.3 ≈ 50. 거의 모든 카드를 써야 하고 dmgMul 은 지속 피해에 안 붙게 해서 최종 보스(2095)도 40초 이상 → 허용. 화염 저항(월드 4)에서 반토막.
- **치명 몰빵**: 0.05+0.10+0.20 = 35%, 배수 3.05 → 기대 ×1.72. 상한 `CRIT_CAP 0.6` 이라 폭주 없음 (수정 공은 이번 판에서 제외해 치명 과잉을 막음).
- **평정심**: 마비·기울임·밀치기를 거의 지운다 → 월드 5에서 강하지만 희귀 + 특성 1칸 소모, 데미지는 0이라 허용.
- **분신+자석+거대화**: 몸통 타격이 늘지만 몸통 12는 스테이지마다 고정이고 판 위 공 최대 3, 추가 공 소실은 손해 없음 → 최대 약 2.5배. 전설+희귀 2장을 써야 하므로 허용, 테스트 후 분신 25초→30초 조정 여지.
- **꿰뚫기+적응**: 적응 중에도 0.85 → 적응을 거의 무시. 의도된 대응이며 희귀.
- 공 수: 시작 예비 3 + 보스 4회(+1) + 여분 공 최대 3, 상한 5 → 후반 실수 여유는 있지만 무한 생존 없음.
